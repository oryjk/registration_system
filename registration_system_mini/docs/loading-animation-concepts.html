加载动画方案预览 · 队员踢球主题（动效版）

四个方案均已带上循环动画：A 摆腿射门→球沿轨迹飞出；B 贴纸果冻抖动+球回弹；C 四肢对角摆动+场地滚动+球旋转；D 球原地 squash & bounce 弹跳。全部沿用 Neo 设计语言，选定后我把动效等价迁移到小程序（view + CSS / 图片 + transform）。

ink 墨色 lime 青柠 surface 纸面 canvas 画布 amber 皮肤 danger 动作标记
方案 A

射门瞬间 · 剪影大场景

动画设想：踢球腿从后摆到触球小幅循环，足球沿虚线弧线飞出；适合首页首屏 / 整页加载位，气势最足。

正在进入球场……

落地方式：剪影细节多，建议按帧导出 PNG/SVG 图片资源，外层 view 做 transform 循环动画（腿摆 + 球位移）；文案三点呼吸另用 CSS。

方案 B

贴纸小人 · 卡片式

动画设想：贴纸部件果冻式抖动（头/手臂/球交替小幅摆动），足球压缩回弹；与现有 Neo 卡片骨架同构，适合嵌在卡片骨架内部或弹窗加载。

拼装球队阵容……

落地方式：肢体用「粗描边胶囊」可在 view + CSS 里用双层 view（外层墨色、内层彩色、圆角胶囊）复刻，不需要图片资源；每个部件独立关键帧动画。

方案 C

带球狂奔 · 无限跑动条

动画设想：球员固定在画面中，地面/草/锥桶/角旗向左无限滚动（两层视差），手臂腿部循环摆动；适合通栏位置（列表顶部、骨架中部）。

奔向球场中……

落地方式：球员可静态（或手臂/腿两帧切换），滚动用一条超出容器的横向 view + 循环 translateX 即可，overflow: hidden 裁切；锥桶/角旗第二层慢速视差。

方案 D

颠球热身 · 弹跳球

动画设想：球在脚背上方原地反复弹起（squash & stretch 挤压回弹），球员头部/手臂轻微跟随晃动，触球瞬间星标闪现；实现成本最低，适合「我的」页、次级页加载。

热身准备中……

落地方式：人物完全静态，只需给球加一个 translateY + scaleY 关键帧（弹起拉伸、触地压扁），实现成本四个方案里最低，纯 view + CSS。

说明：本页为浏览器预览稿，用 SVG 绘制。微信小程序模板不支持内联 SVG，落地时：方案 B / D 用 view + CSS 纯代码拼装即可（双层胶囊肢体：外层墨色、内层彩色）；方案 A / C 建议把人物导出为图片资源，动画用外层 view 的 transform 实现。四个方案均沿用 neo-tokens.css 的既有 token（ink / lime / surface / amber / danger），不引入新颜色。
