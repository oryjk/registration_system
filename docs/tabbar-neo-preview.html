我的
完整 neo 容器：选中项是带描边 + 硬阴影的青柠 pill。需 custom tabbar 组件，mp-weixin 端要处理切换闪烁与选中态同步

方案 A 改动点（pages.json）

backgroundColor: #fffdf8（surface）
color: #4d514b（text-muted）
selectedColor: #111310（ink）
选中图标：青柠块 + 墨线 glyph 烘焙进 PNG

方案 B 额外能力

选中 pill：background: #b9f24b + 2px 墨描边 + 3px 3px 0 硬阴影
容器：顶部 2px 墨线，与页面卡片同一套描边语言
代价：custom: true + 自绘组件 + 各 tab 页同步选中态

不变的约定

四个 tab 与顺序不变：首页 / 约队 / 统计 / 我的
图标隐喻不变（房子 / 地球 / 柱状图 / 人像），只做 neo 化 redraw
配色全部引用 neo-tokens.css 既有 token，不新增色值
