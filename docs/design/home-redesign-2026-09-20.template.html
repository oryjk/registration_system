三个问题

这不是一次换肤。视觉语言保持不变——青柠、暖白、墨色、黑边、硬阴影——变化的是信息架构与动作路径：首页从「什么都摆一点」改成一个能立刻告诉用户「现在该做什么」的页面。

02

设计策略

信息架构重组
视觉语言不变

把首页的角色收敛成一个：「现在」页。用户进来时，页面按顺序回答三个问题——每个问题恰好对应一个页面区域，也分别化解「不知道怎么操作」「没有重点」「乱」。

QUESTION 01

我现在最该
做什么？

把 banner 位和首卡合并成一张「现在卡」：全页唯一的深色块、唯一的青柠大按钮，动作直达（点按钮直接弹报名面板，不再先跳详情）。

化解「不知道该如何操作」
QUESTION 02

比赛卡怎么
不冗余、有主次？

保留你熟悉的卡片结构（左日期栏、进度、头像行），只做减法：假按钮标签退场、时间块换成开赛时间、截止时间降级到按钮旁小字。

化解「乱、信息冗余」
QUESTION 03

我报没报、
状态是什么？

按钮即状态：去报名 = 没报，已报名 = 已报，已请假 = 请假。不再用「我的状态」标签复述一遍，一个元素说清状态和动作。

化解「没有重点」
一屏一个动作青柠大按钮全屏只有一个（现在卡 CTA），「＋」是导航不算动作。
按钮即状态去报名 / 已报名 / 已请假 三态即全部状态语义，不再用标签复述一遍。
深色与青柠是稀缺资源深底只留现在卡一处，青柠只留 CTA 与「＋」。
决策信息优先于装饰「还差 6 人成行」提为现在卡内的次强调，先于场地、对手。

品牌 banner / 下一场 hero与首卡同一场比赛，双深色块、双按钮并入「现在卡」，全页唯一深色块；列表不再重复展示首场
卡片顶部双标签（线上约队 / 报名中）像按钮可点；「报名中」与「可报名」互为废话「线上约队」并入场地行小字；「报名中」删除

「去掉硬阴影，还算 Neo 吗？」顶部导航「硬阴影」开关可整稿切换对比

仍算。Neo 的骨架是墨描边 + 平涂色 + 近直角 + 重字重，硬阴影只是其中最响的一个特征；纯描边的 outline-neo 在粗野主义设计里是常见变体。去掉后气质从「贴纸般的立体感」转向「线稿感」，更安静、更平。

但有三个连锁问题：① 一致性——大厅、统计、我的等页面仍带 8rpx 墨阴影，单独去掉首页会像另一个 app，要做就得在 token 层全系统统一；② 按压反馈——现有 Neo 按压语言是「位移 + 阴影收短」，无阴影后需换成底色加深或反色；③ 可点性——青柠按钮少了投影的「凸起」暗示，需要靠按下态补回。

我的倾向是折中：行、chip、次级元素本来就无阴影，只保留现在卡和「＋」两个锚点的投影——既有立体焦点，又不满页投影。整页去阴影也成立，前提是全系统一起做并重做按压反馈。
