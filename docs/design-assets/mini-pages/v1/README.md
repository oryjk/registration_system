# 微信页面视觉延伸验收记录

2026-11-03，用户要求将首页已确认设计推广到其他页面，并明确「不用管 H5，只需要管小程序」。本轮只以微信页面和产物为交付目标。

## 实现范围

- 共享：57 个 Lucide/本地足球线稿图标、原生 `AppIcon`、单个细线方向箭头、全部 Tab 的白色悬浮底栏与薄荷选中项；统一卡面、辅助文字和小按钮热区。
- 个人服务：18 个 Vue 文件，覆盖个人中心、我的比赛、钱包/账单、消息/队长留言、资料、帮助/设置/联系和荣誉页面展示。审核隐藏、支付/授权及海报导出保留。
- 比赛与场地：25 个 Vue 文件，覆盖大厅/搜索/发布、比赛详情/接约/名单/报名人数、场地选择与地图控件。原生地图结构、报名/支付/校验/权限与真实状态保留。
- 球队与统计：24 个 Vue 文件，覆盖日历/活跃榜、建队/加入/详情/邀请/队费及队员/出勤/财务管理。排名、会员、余额、危险动作和固定确认区行为保留。
- 合理例外：web-view 文档、原生地图内部、荣誉海报画布与导出内容沿用原实现；已批准首页主卡和新手引导不重新设计。

## 验证

- `bun run type-check` 通过。
- 104 个现有 source 测试文件隔离运行，673 项通过。逐文件进程隔离用于避免已有 `mock.module` 跨文件污染，汇总见 `test-verification.json`。
- `MINI_REVIEW_SKIP=1 bun run build:mp-weixin` 通过；27 个页面、3 个普通分包、组件注册和生产 API 校验通过。
- 122 个原生 PNG（含 default/muted 和底栏状态）全部进入编译目录；PNG + SVG 共 161,598 字节。主包本地文件总计 1,391,520 字节（约 1.33 MiB），微信最终上传尺寸以微信返回为准，见 `resource-verification.json`。
- 个人中心、大厅、比赛详情、统计各做 393px/320px 排版预览，八组均无页面横向溢出或缺失图标。检查了缠观审核隐藏/恢复和统计分页切换，见 `visual-verification.json`。
- 主代理 review 与独立只读 review 均未发现阻断问题。

## 截图说明

`mine-*`、`hall-*`、`detail-*`、`stats-*` 是实际 MP-WEIXIN 组件模板/样式的浏览器排版预览。个人中心挂载实际页面并用示例状态替代接口；大厅、详情和统计组合实际展示组件，搜索占位等外壳为验收夹具。uni 原生节点与 Wot 控件使用浏览器适配器，因此不代表微信开发者工具或真机截图，也不构成登录、支付、原生地图或 API 验收。示例资料与数据不写入产品代码。

当前 Linux 环境没有微信开发者工具，原生宿主布局、swiper、弹窗、安全区和实际触摸效果仍需微信端验收。按用户最新要求，未执行 H5 构建或单独验收。
