# 微信小程序点阵箭头实施计划

**目标**：按用户提供的参考图绘制透明 SVG，并统一微信小程序的方向箭头；H5 保持原样。

**设计**：实心人字形箭头与七排圆点尾迹，保留原图比例。方向跟随原有动作，颜色继承现有语义色，左右翻转、上下旋转以及双箭头均保留对应含义。

**方案**：保留 SVG 原稿，从同一份 SVG 生成内嵌 WOFF 字体，覆盖 Wot 的方向图标；文字箭头使用该字体，CSS 尖角替换为相同字形。选择字体而非逐个加载 SVG 图片，是为了继承颜色、覆盖 Wot 内部日历箭头，并避免图片请求及遮罩兼容问题。

**范围**：仅自有页面和 Wot 组件中的方向指示；微信宿主及系统原生选择器不属于项目可替换范围。编辑铅笔、播放、分享等具有独立含义的图标保持原语义。
