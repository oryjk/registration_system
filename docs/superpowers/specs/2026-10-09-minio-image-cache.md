# 小程序 MinIO 图片缓存

用户已确认按 URL 更新图片、无需重新发版，并要求实现统一本地缓存。

- 微信小程序内所有本站 MinIO 图片（registration、seat-images 桶公开地址）统一缓存；本地包图、临时文件、外部图片不改变。
- 下载超时 15 秒。普通图片有效期 7 天，文件名包含 16–64 位内容 hash 的版本图片长期复用；文件丢失或地址变化重新下载。
- 同 URL 合并并发下载，最多同时下载 4 张；保存持久路径，下次启动校验文件后直接复用；迁移已有荣誉背景缓存。
- 缓存限制 8 MiB / 128 文件，按最后使用时间清理。超限大图或保存失败仍可使用临时文件；下载失败可使用过期缓存，没有旧文件时保持原来的远程图片回退。
- 正在使用的原生图片路径在组件卸载前保留，避免清理后页面坏图；容量全部占用时新增/刷新图片使用临时文件。索引无法保存时不留下无法追踪的持久文件。
- 页面使用原生 image 和现有样式，通过 composable 解析 src，过期异步回调和卸载页面不能替换新图片。
- 首页/大厅/比赛/球队分享仍同步返回封面；进入页面预取本地路径。球队队徽、荣誉图、小程序码合成及联系二维码大图预览共享缓存。
- H5 保持浏览器 HTTP 缓存，不使用小程序文件系统。
- 保持 API、分享标题/路由、UI 布局和后端不变。
