# 小程序资料编辑页 Soft Neo-Brutalism 改造设计

## 目标

将小程序/H5 的资料编辑页与已确认的“我的”页 Soft Neo-Brutalism 风格统一，同时保留现有资料加载、头像选择、昵称编辑、手机号绑定、表单校验、保存和返回逻辑。

## 视觉方案

- 页面背景使用现有 `--neo-color-page`，取消渐变、柔光阴影和超大圆角。
- 顶部使用深色 `NeoSurface` 作为资料编辑 Hero，展示当前头像、页面标题和同步说明；头像缺失或加载失败时使用本地默认头像图标。
- 表单使用浅色 `NeoSurface`，保留清晰的 `基础资料` 分区标题、硬边框和实体偏移阴影。
- 输入框使用浅色硬边输入控件；选择头像使用荧光绿主按钮；保存使用深色块级 `NeoButton`，不可提交时使用 disabled 状态。
- 手机号绑定仅在运行时配置开启时出现，微信原生 `open-type` 继续使用条件编译，H5 不展示微信专属绑定按钮。
- 所有新增样式使用 `rpx`、`hover-class` 和现有 Neo 设计 token，兼容 H5 与微信小程序。

## 数据与交互

- 页面仍由 `index.vue` 负责业务编排，子组件只接收数据并发出用户意图；本次页面规模保持在单页职责边界内，不新增无必要的抽象层。
- `handleChooseAvatar`、H5 `chooseImage` 降级、手机号绑定和 `handleSubmit` 的 API 调用不改变。
- 头像预览增加加载失败回退，避免远程头像失败时出现空白头像区域。
- Mock 当前用户不依赖外部占位图地址，直接验证本地头像回退；真实后端返回的头像地址仍优先展示。
- 首次完善资料仍要求头像和昵称；编辑已有资料时允许只修改昵称并保留本地头像回退。
- 返回按钮、保存成功返回和首次登录完善资料后的跳转行为保持现状。

## 验收标准

- 从“我的”页点击“编辑资料”后，资料编辑页首屏呈现与“我的”页一致的硬边框、实体阴影、深色/荧光绿配色。
- 已有昵称被正确填充；编辑昵称后保存按钮状态和提交行为保持可用。
- H5 页面不出现微信专属按钮；微信构建可以通过。
- 390×844 和默认桌面视口无横向溢出、无空白页、无框架错误覆盖层。
