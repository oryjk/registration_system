# 微信首页图片增强

用户已确认本聊天生成的首页设计稿，要求落地微信小程序，H5 不变；先生成素材并上传 MinIO，再接入界面。

- 沿用深蓝、薄荷绿、浅表面与轻描边。首页引导区使用夜场足球照片，三个等宽入口使用独立透明插画，地图入口使用球场地图插画。
- 保持入口权限、审核过滤、引导定位、跳过记忆和原导航。保留真正的比赛、状态、日期和比分，不引入设计稿中的示例业务数据。
- 已结束比赛增加小幅封面：优先比赛创建时的 `cover_image_url`，未配置时从新生成的十张默认图片中按比赛 ID 稳定分配。自定义图加载失败同样回退默认池，默认图失败最终降级为图标，不循环重试。
- 默认图包含夜场球场、草地足球、球门球网，以及七张同风格足球场景。只扩展微信首页查看卡及其更多列表，不改变待处理行动卡原有封面语义。
- 上传手机适用的压缩版：背景宽约 1000px、透明入口图 256px、地图宽约 640px、列表图 320px。原图保存在生成工具输出目录；仓库保留压缩素材、提示词、清单与公网校验记录。
- 素材使用新 MinIO 对象与内容哈希命名，沿用缓存及公开只读前缀，不覆盖旧素材，不改数据库及后端。

已评估方案：整页背景会降低信息清晰度；只换小图标提升有限。采用用户确认的局部照片、入口插画和列表缩略图组合。
