# Go 小程序首页 HTML 原型设计

## 目标

在正式修改 `registration_system_mini_go/` 前，先交付一个可直接用浏览器打开的高保真首页 HTML 原型，用于确认首页的信息层级、视觉样式、移动端布局和基础交互。

原型以用户在当前任务中提供的 487 行 React 静态稿为视觉依据，但不依赖该附件才能实施：本规格在下文完整列出页面区域、固定文案、演示数据和状态变化。原型不引入 React、Tailwind、uni-app 或 Go 接口。原型确认后，另行规划 Vue 组件拆分、真实 DTO、状态管理和接口接入。

## 交付物

- 文件：`docs/prototypes/go-mini-home.html`
- 形式：单个 HTML 文件，内含 CSS 和少量原生 JavaScript
- 运行：无需安装依赖或启动开发服务器，浏览器直接打开即可
- 目标视口：以 390px 至 420px 宽的手机为主，最小支持 360px；桌面端居中展示最大宽度 420px 的手机画布

## 页面结构

页面从上到下包含以下区域：

1. 预览状态栏：显示 `22:17`、信号、网络和电量，仅用于 HTML 视觉预览。正式小程序使用平台状态栏和安全区。
2. 首页头部：页面标题 `首页`、位置标识 `成都 · 高新区`、更多和定位图标按钮。
3. 主视觉：深绿色足球主题横幅，依次显示 `GOAL!`、`约球开踢`、`组队 · 报名 · 上场` 和 `去看看 →`。
4. 最近比赛：标题为 `最近要处理的比赛`，包含 `HOT` 标识和 `全部比赛` 入口。单张比赛卡片的固定演示数据见“演示数据与交互”。
5. 约队机会：标题为 `约队机会`，辅助文案为 `展示当前时间之后开始的约队比赛`，右侧入口为 `进入大厅`。空状态显示 `当前还没有可关注的约队机会`、`你可以去大厅发布一条`、`或等待其他球队发起` 和 `去大厅看看`。
6. 底部导航：首页、约队、中间发布按钮、统计、我的五个入口；首页为默认激活态。

## 视觉规则

- 主色使用 `#4CAF50`，搭配深绿色主视觉、白色内容表面和 `#F5F5F5` 页面背景。
- 保留参考稿紧凑、清晰、偏工具型的移动界面，不添加营销文案或额外功能区。
- 卡片圆角不超过 14px；按钮、状态标签和头像可以使用胶囊或圆形外观。
- 字体栈使用 `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`，但不发起远程字体请求；原型可用性不依赖本机是否安装 Inter。
- 使用一致的 CSS 变量管理颜色、边框和文字层级，避免把参考稿中的内联样式逐项照搬。
- 熟悉的操作图标使用 Lucide 的标准路径，并以内联 SVG 嵌入 HTML；不加载图标 CDN。纯图标按钮必须带 `aria-label`，因此单文件在离线环境下保持视觉和可访问名称完整。

## 演示数据与交互

所有比赛、位置、人数和参与者均为固定演示数据，不代表 Go 后端字段。比赛卡片固定显示：

- 日期 `08/06`、星期 `周四`、截止时间 `20:00` 和说明 `截止报名`。
- 标题 `周四友谊赛`，类型标签 `比赛报名`，状态标签 `报名中`。
- 地点 `驿马河二期`，赛制 `8人制`，对手 `客家人`。
- 报名进度 `10/8`，进度条为 100%，参与者缩略头像依次为 `张`、`李`、`王`、`赵`、`陈`，说明为 `已达成行`。
- 参与者颜色依次为 `#4BA59E`、`#E07B4B`、`#9B6FD4`、`#4B8BE0`、`#D44B6F`。

报名状态只有以下两种，初始为已报名：

| 状态 | 按钮 | 我的状态 | 状态点 |
| --- | --- | --- | --- |
| 已报名 | `已报名 ✓`，绿色实心 | `我的状态：参加` | 绿色 |
| 未报名 | `去报名`，白底描边 | `我的状态：未参加` | 灰色 |

- 点击报名按钮一次切换到另一状态，再点击一次恢复初始状态；按钮宽度固定，切换时卡片不得发生布局跳动。
- 底部普通导航项可切换激活样式，但不切换页面；同一时刻只允许一个普通导航项激活，初始为 `首页`。
- 中间发布按钮、头部图标和内容入口提供按压反馈，不执行路由、弹窗或网络请求。
- 所有按钮使用真实 `button` 元素，并提供可识别的 `aria-label`。

## 响应式与安全区

- 360px、390px 和 420px 手机宽度下页面占满视口，正文自然纵向滚动；文字允许正常换行，卡片内部不得横向滚动或裁切。
- 桌面宽度下使用中性灰背景并将页面居中，最大内容宽度为 420px。
- 底部导航固定在手机画布底部，正文预留足够底部空间，避免内容被遮挡。
- 底部导航考虑 `env(safe-area-inset-bottom)`；HTML 预览状态栏不参与正式端实现。
- 固定尺寸的日期块、头像、图标按钮和导航项使用稳定尺寸，交互状态不得导致布局跳动。

## 边界

本阶段不做以下事项：

- 不修改 `registration_system_mini_go/src/`。
- 不调用 `/api/matches`、登录、球队或报名接口。
- 不定义或推断正式 DTO、业务状态和错误处理。
- 不实现约队、统计、我的、发布或比赛详情页面。
- 不把原型 JavaScript 作为后续生产代码直接复用。

## 验收

- HTML 文件能够直接打开且无构建依赖、远程资源和非预期网络请求，浏览器控制台无错误。
- 在 360x800、390x844、420x900 和 1440x1000 视口下没有横向溢出、文字遮挡或底部导航覆盖正文。
- 首页六个区域、固定文案和演示数据与本规格一致。
- 报名状态与底部导航的本地演示交互可用。
- 页面不发起 Go API 请求，也不修改浏览器持久化状态。
- 原型经用户视觉确认后，才进入 uni-app 正式页面和 Go 接口对接设计。
