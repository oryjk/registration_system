# 微信报名页表面层次

用户已确认上一轮建议，并要求先在报名页面试用。目标页面是 `pages/matches/detail`：比赛信息、报名进度、队员名单、说明及管理区使用清晰独立的卡片；页面浅中性底，卡片使用主题 surface、圆角与柔和阴影。保留卡片内部的分隔线、语义色和底部操作。

选择浅底加柔和表面层次：只恢复外框会回到层层描边，仅增加留白无法解决同底色融合；完整浮雕新拟态装饰较重，本轮不采用。浅色与深色主题分别使用明确的主题页面底色。

复用 AppSurface，以内容区继承的可选 CSS token 定制其微信圆角与阴影；默认普通页面不变，浮层不继承内容区覆盖。无名单时的队长入口复用同一容器。新增颜色集中在 primitive/semantic token，页面尺寸引用既有尺度。不改 H5、API、权限、报名、支付、弹层、分享与导航流程。
