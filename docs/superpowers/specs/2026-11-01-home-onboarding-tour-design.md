# 首页新手漫游

用户已选择统一三步介绍并要求实施。目标是让第一次进入首页的队长、队员和找球踢用户知道从哪里开始。

## 方案

- 采用：高亮「创建我的球队 → 加入已有球队 → 找一场球踢」，背景变暗，说明卡提供圆点、上一步、下一步、关闭/跳过和完成。
- 比较方案：先选择目标再分流，说明更聚焦，但增加选择负担；本次采用用户选定的统一介绍。
- 不强制登录、补资料或实际创建/加入球队；说明入口用途，实际业务沿用已有流程。

## 行为与边界

- 首页加载成功、页面可见且审核配置已就绪后启动；播放期间展示统一入口卡，结束后恢复原首页。
- 首次按本机当前账号记录；游客独立记录。完成/主动跳过后不自动重播，与现有指引收起状态互不影响。已有账号尚无记录时也会看到一次（实现默认）。
- 使用帮助提供「重新查看新手引导」，返回首页后主动重播，不受首次记录限制。
- 直接打开邀请或比赛分享不跳走；首页 scene 跳转不自动弹引导。页面隐藏、切号、失败或缺少目标时关闭，不能留下阻挡页面的遮罩。
- 审核态遵循现有创建入口限制，只介绍加入球队和找球踢，不绕过权限。
- Wot UI 2.3.0 Tour + Root Portal；Vue/uni API；复用设计 token 与主题，不改后端契约、不添加依赖。
- 首页和引导状态分开，现有比赛数据、身份偏好与正常业务入口保留。

## 验收

- 三步高亮正确，窄屏说明卡可操作，关闭与完成能恢复原首页。
- 首次、再次进入、切号、手动重播、分享跳转与审核态行为正确。
- 补充状态行为测试；运行类型检查、微信构建（跳过版本登记）、H5 构建及浏览器交互检查。
