# 微信页面轻量视觉统一

用户已确认首页的无内框入口、极浅主题底、独立圆角照片和分隔列表，要求其他页面沿用，并明确复用相同组件、样式值集中 token 化。现有业务、接口、权限、审核态、支付及 H5 保持原状。

覆盖全部微信页面：约队大厅、比赛详情/发布/接约、球队创建/加入/详情/邀请/队费/管理、统计、我的/设置/个人资料/帮助/开发者联系、账单、通知/留言、荣誉与球场入口。web-view 保持原生嵌页，海报画布内部设计和地图原生布局不重做。

统一规则：默认内容区无外框和卡片投影，以分区间距、列表行及细分隔线表达层级；强调摘要与低频入口用极浅主题底；表单保留输入边界，主操作、危险语义、选中状态和点击热区清晰。数字、长标题、地点和金额均保留完整展示。

在 design-tokens.css 建立共享间距/文字/尺寸/面板/列表/表单/引导 token，新增微信规则只引用这些 token。旧 H5 原始样式保留在条件编译外，微信覆盖块使用 token。AppSurface、SectionHeader、AppButton 在微信端统一轻量表现；增加可复用的 AppPageIntro，创建/加入等介绍复用它。可导入的 list-surfaces.css 为原生 wrapper 提供统一分区和列表样式，避免父 scoped 穿透子组件。

不为纯视觉改动机械增加单元测试。运行类型检查、现有完整前端测试、微信构建/组件/分包/API 校验；对代表性页面进行 320/375px、多主题、长文案和表单状态的组件预览。说明真机未验收的范围，验证后默认提交、合并 main 并推送。
