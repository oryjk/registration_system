# 公众号推文发布指南

## 文件清单

| 文件 | 用途 |
| --- | --- |
| `比赛报名-公众号推文.html` | 排版好的文章正文（含全部插图），在浏览器打开后全选复制，直接粘贴进公众号编辑器 |
| `封面-900x383.png` | 头条封面（2.35:1），在公众号编辑器「封面」处手动上传 |
| `封面-500x500.png` | 备用方版封面（1:1），适合次条或朋友圈分享缩略 |
| `assets/` | 文章 HTML 引用的图片（截图 10 张 + 首图 banner） |
| `screens/` | 原始页面截图（390×844 逻辑像素 @3x，1170×2532），备用 |

## 发布步骤（重要，按顺序来）

1. **用 Chrome 打开** `比赛报名-公众号推文.html`（双击或拖进浏览器）。
   - 必须用本机 Chrome / Edge 打开，图片才能一起进剪贴板。
2. 在页面里 **Cmd + A 全选 → Cmd + C 复制**。
3. 打开公众号后台「新建图文」，在**正文区点击一下，Cmd + V 粘贴**。
   - 图片会自动上传为素材（稍等进度条走完），文字样式（加粗、色块标题、图注、CTA）会原样保留。
4. 标题填：**踢了十年野球，我终于不用在群里数人头了**
   - 备选：《周五的球，再也不用靠群里接龙了》《被放鸽子十年后，我把约球这件事交给了一个小程序》
5. **封面**：上传 `封面-900x383.png`（头条 2.35:1 裁切安全）；次条或朋友圈用 `封面-500x500.png`。
6. 摘要建议：`组球靠接龙、收钱靠催、出勤靠记忆？这个小程序把业余足球的破事全管了：约队大厅、散人凑局、到场签到、赛后 AA、出勤排名。`
7. 发布前用「预览」发到自己微信检查一遍图片清晰度。

## 常见问题

- **粘贴后图片丢失**：确认是用本机浏览器打开 HTML 文件（file:// 协议）后复制的；不要用 VS Code 等编辑器预览复制。
- **粘贴后样式丢失个别元素**：微信编辑器偶尔过滤个别圆角/阴影，不影响阅读；如需要可在公众号编辑器里微调。
- **双图并排变上下**：个别客户端渲染差异，可忽略；若在意可删掉其中一张。
